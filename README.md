# Async Test Framework

Современный фреймворк для асинхронного тестирования REST API.

Проект демонстрирует навыки автоматизации тестирования на Python с использованием:
- pytest / pytest-asyncio
- httpx (асинхронный HTTP-клиент)
- SQLAlchemy (проверка данных в БД)
- pydantic (валидация данных)

## 🔧 Установка

```bash
git clone https://github.com/username/async-test-framework.git
cd async-test-framework
pip install -r requirements.txt
